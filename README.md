# Attendance Manager Portal

A production-style React + Vite HR attendance dashboard for tracking employee presence, absences, and attendance insights.

## Features
- Executive dashboard with attendance KPI cards
- Weekly attendance trend visualization
- Search and filter employee attendance by name, ID, team, and status
- One-click status toggle (Present / Absent)
- Responsive, professional UI suitable for HR operations

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
